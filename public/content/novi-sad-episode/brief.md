# Serbia, Self-Planned — Novi Sad

- Slug: novi-sad-episode
- Platform: longform

## Reference

No new reference — this is Episode 2 of the same pilot series as
`serbia-sample-episode` (arrival day, Belgrade), which that episode's
closing line already teased: "다음 편은 노비사드." Same house style,
same couple, next day: Belgrade → Novi Sad.

This episode also exists to demonstrate a house-voice fix: the Belgrade
episode's script reads as single-voice reporting narration, not the
"둘이 계획하고, 둘이 떠난다" couple banter the positioning calls for.
See `serbia-sample-episode/brief.md`'s "Competitor voice/narration
breakdown" for why, and `script-writer.md`'s voice rules for the fix —
write informational/logistics beats as an actual exchange between the
two of them wherever the information naturally splits into a question/
confirmation or observation/reply.

## Goal

Same as Episode 1: competence and warmth, not hardship or spectacle —
but this time proving the two-voice-exchange fix actually reads as
banter, not narration-with-extra-steps. Day 2: Belgrade to Novi Sad,
Petrovaradin Fortress, old town, riverside.
